# CLI

These pages cover CLI for Better Agent.

## When to Use This Section
The CLI pages explain how to run Better Agent from the terminal: command purpose, required configuration, supported flags, safe defaults, and what to verify after the command finishes.

## Available Pages
- [CLI Usage](/docs/api/cli/usage) - The repository exposes a command-line entrypoint and runtime flags.

## Reading Order
- Start with the command purpose before copying flags.
- Check required environment variables before running commands that create, mutate, or seed data.
- Prefer the smallest safe script first, then increase scale or concurrency after verification.
