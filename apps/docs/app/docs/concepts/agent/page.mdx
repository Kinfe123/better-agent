# Agent

An agent is the core unit of behavior in Better Agent. It brings together a model, instructions, tools, and runtime behavior into one typed definition. At minimum, an agent needs a `name` and a `model`.

```ts
import { defineAgent } from "@better-agent/core";
import { openai } from "./openai";

export const helloAgent = defineAgent({
  name: "hello",
  model: openai.model("gpt-4o"),
});
```

## Instructions and Context

Use `instruction` for the agent's system behavior. It can be a static string or a function driven by validated runtime context.

```ts
const writer = defineAgent({
  name: "writer",
  model: openai.model("gpt-4o"),
  instruction: "You are a concise technical writer.",
});
```

Use `contextSchema` to define typed, validated runtime data for a run — like the current user, plan, or workspace. Any Standard Schema library (Zod, Valibot, ArkType) works here.

```ts
import { z } from "zod";

const supportAgent = defineAgent({
  name: "support",
  model: openai.model("gpt-4o"),
  contextSchema: z.object({
    userId: z.string(),
    plan: z.enum(["free", "pro"]),
  }),
  instruction: (context) =>
    `Help user ${context.userId}. They are on the ${context.plan} plan.`,
});
```

## Tools

Tools let the agent act. Pass a single tool or an array. When a tool fails, the default behavior sends the error back to the model so it can recover. Use `toolErrorMode: "throw"` when you want the run to fail instead.

```ts
const assistant = defineAgent({
  name: "assistant",
  model: openai.model("gpt-4o"),
  tools: [weatherTool, stockTool],
});
```

See [Tools](/docs/concepts/tools) for defining tools, client tools, approvals, and error recovery.

## Steps

Each step produces one model response. If that response includes tool calls, the results feed into the next step. The loop continues until the model finishes naturally, a stop condition is met, or the step limit is reached.

Use `maxSteps` to cap how many steps a run can take, and `stopWhen` to end a run based on your own workflow rules.

```ts
const researcher = defineAgent({
  name: "researcher",
  model: openai.model("gpt-4o"),
  tools: [searchWeb, readPage],
  maxSteps: 5,
});
```

## Output Schema

Attach `outputSchema` to get a typed, validated JSON response from the model on every run. The schema field accepts any Standard Schema library or a raw JSON Schema object.

```ts
const summaryAgent = defineAgent({
  name: "summary",
  model: openai.model("gpt-4o"),
  outputSchema: {
    schema: z.object({
      summary: z.string(),
      wordCount: z.number(),
    }),
  },
});
```

See [Structured Output](/docs/concepts/structured-output) for reading results and per-run overrides.
