# Agent

An agent is the core unit of behavior in Better Agent. It brings together a model, instructions, tools, and runtime behavior into one typed definition. At minimum, an agent needs a `name` and a `model`.

```ts
import { defineAgent } from "@better-agent/core";
import { openai } from "./openai";

export const helloAgent = defineAgent({
  name: "hello",
  model: openai.model("gpt-4o"),
  description: "Greets users and answers general questions.",
});
```

## Instructions and Context

Use `instruction` for the agent's system behavior. It can be a static string or a function that receives validated context.

```ts
const writer = defineAgent({
  name: "writer",
  model: openai.model("gpt-4o"),
  instruction: "You are a concise technical writer.",
});
```

Use `contextSchema` to define typed, validated runtime data for a run — like the current user, plan, or workspace.

```ts
import { z } from "zod";

const supportAgent = defineAgent({
  name: "support",
  model: openai.model("gpt-4o"),
  contextSchema: z.object({
    userId: z.string(),
    plan: z.enum(["free", "pro"]),
  }),
  instruction: (context) =>
    `Help user ${context.userId}. They are on the ${context.plan} plan.`,
});
```

When you register the agent in `betterAgent`, pass the matching `context` when you run it.

## Tools

Tools let the agent act. Pass a single tool or an array.

```ts
const assistant = defineAgent({
  name: "assistant",
  model: openai.model("gpt-4o"),
  tools: [weatherTool, stockTool],
});
```

When a tool fails, the default behavior sends the error back to the model so it can recover. Use `toolErrorMode: "throw"` to fail the run immediately instead. See [Tools](/docs/concepts/tools) for defining server tools, client tools, approvals, and error recovery.

## Steps

Each step produces one model response. If that response includes tool calls, the results feed into the next step. Use `maxSteps` to cap how many steps a run can take.

```ts
const researcher = defineAgent({
  name: "researcher",
  model: openai.model("gpt-4o"),
  tools: [searchWeb, readPage],
  maxSteps: 5,
});
```

Use `stopWhen` when a run should stop based on your own workflow rules rather than the model's natural finish.

```ts
const researchAgent = defineAgent({
  name: "research",
  model: openai.model("gpt-4o"),
  contextSchema: z.object({ plan: z.enum(["free", "pro"]) }),
  tools: [searchWeb, readPage],
  maxSteps: 6,
  stopWhen: ({ stepIndex, context }) =>
    context.plan === "free" && stepIndex >= 1,
});
```
