# Agent

An agent is the core unit of behavior in Better Agent. It brings together a model, instructions, tools, and runtime behavior into one typed definition. At minimum, an agent needs a `name` and a `model`.

```ts
import { defineAgent } from "@better-agent/core";
import { openai } from "./openai";

export const helloAgent = defineAgent({
  name: "hello",
  model: openai.model("gpt-4o"),
});
```

You can add a human-readable `description` to help readers understand what the agent does.

## Instructions and Context

Use `instruction` for the agent's system behavior. It can be a static string or a function that receives validated context.

```ts
const writer = defineAgent({
  name: "writer",
  model: openai.model("gpt-4o"),
  instruction: "You are a concise technical writer.",
});
```

Use `contextSchema` to define typed, validated runtime data — like the current user, plan, or workspace — that the instruction function can read.

```ts
import { z } from "zod";

const supportAgent = defineAgent({
  name: "support",
  model: openai.model("gpt-4o"),
  contextSchema: z.object({
    userId: z.string(),
    plan: z.enum(["free", "pro"]),
  }),
  instruction: (context) =>
    `Help user ${context.userId}. They are on the ${context.plan} plan.`,
});
```

When you register the agent in `betterAgent`, pass the matching `context` field when you call `run()` or `stream()`.

## Tools

Tools let the agent act on the world. Pass a single tool or an array.

```ts
const assistant = defineAgent({
  name: "assistant",
  model: openai.model("gpt-4o"),
  tools: [weatherTool, stockTool],
});
```

When a tool fails, the default behavior sends the error back to the model so it can recover. Set `toolErrorMode: "throw"` to fail the run immediately instead. See [Tools](/docs/concepts/tools) for defining contracts, client tools, approvals, and error recovery.

## Steps

Each step produces one model response. If that response includes tool calls, the results feed into the next step. The loop continues until the model finishes naturally, a stop condition is met, or the step limit is reached.

Use `maxSteps` to cap the number of steps a run can take:

```ts
const researcher = defineAgent({
  name: "researcher",
  model: openai.model("gpt-4o"),
  tools: [searchWeb, readPage],
  maxSteps: 5,
});
```

Use `stopWhen` when the run should stop based on your own workflow rules, not just the model's natural finish.
