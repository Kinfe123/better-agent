# CLI

The Better Agent CLI generates a `.d.ts` file from your app's agent definitions. This gives your client full type safety — typed agent names, context schemas, and tool contracts — without importing server code into your client bundle.

## Generate Client Types

```bash
npx @better-agent/cli generate type --config ./server.ts
```

Or with the global command:

```bash
better-agent generate type --config ./server.ts
```

This discovers exported `betterAgent()` instances in the config file, extracts agent and tool type information, and writes a portable type declaration.

## Options

| Option | Default | Description |
| --- | --- | --- |
| `--config <path...>` | — | One or more config file paths. Required. |
| `--cwd <path>` | `process.cwd()` | Base directory for resolving relative paths. |
| `--out <path>` | `better-agent.types.d.ts` | Output path for the generated `.d.ts` file. |
| `--name <identifier>` | `BAClientApp` | Exported type alias name. |
| `--yes` | `false` | Skip prompts and overwrite the output file. |

## Example

```bash
npx @better-agent/cli generate type \
  --config ./server.ts \
  --out ./src/types/better-agent.d.ts \
  --name MyApp \
  --yes
```

This produces a `better-agent.d.ts` file you can import on the client:

```ts
import { createClient } from "@better-agent/client";
import type { MyApp } from "./src/types/better-agent";

const client = createClient<MyApp>({
  baseURL: "https://api.example.com",
  secret: process.env.BETTER_AGENT_SECRET!,
});
```

## Debug mode

Set `BA_DEBUG=1` to enable verbose output from the CLI. This is useful when a config file isn't being discovered or the generated types don't look right.

```bash
BA_DEBUG=1 npx @better-agent/cli generate type --config ./server.ts
```
