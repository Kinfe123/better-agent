# CLI

The Better Agent CLI generates a `.d.ts` file from your app's agent definitions. This gives your client full type safety — typed agent names, context schemas, and tool contracts — without importing server code.

## Generate Client Types

```bash
npx @better-agent/cli generate type --config ./server.ts
```

Or with the global command:

```bash
better-agent generate type --config ./server.ts
```

This discovers exported `betterAgent()` instances in the config file, extracts agent and tool type information, and writes a portable type declaration.

## Options

| Option | Default | Description |
| --- | --- | --- |
| `--config <path...>` | — | One or more config file paths. Required. |
| `--cwd <path>` | `process.cwd()` | Base directory for resolving relative paths. |
| `--out <path>` | `better-agent.types.d.ts` | Output path for the generated `.d.ts` file. |
| `--name <identifier>` | `BAClientApp` | Exported type alias name. |
| `--yes` | `false` | Skip prompts and overwrite the output file. |

## Example

```bash
npx @better-agent/cli generate type \
  --config ./server.ts \
  --out ./src/types/better-agent.d.ts \
  --name MyApp \
  --yes
```

Set `BA_DEBUG=1` to enable verbose output during type generation.

## Using the Generated Type

Once the file is written, import the type alias in your client:

```ts
import { createClient } from "@better-agent/client";
import type { BAClientApp } from "./better-agent.types";

const client = createClient<BAClientApp>({
  baseURL: "https://api.example.com",
  secret: process.env.BETTER_AGENT_SECRET!,
});
```

The generated type carries the same agent names, context schemas, and output schemas as your server, with no runtime dependency on server code. See [TypeScript](/docs/concepts/typescript) for a deeper look at what the type system infers.
