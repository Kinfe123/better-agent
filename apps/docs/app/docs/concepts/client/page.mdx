# Client

The Better Agent client is a typed HTTP client for talking to a Better Agent server. It gives you full inference for agent names, context schemas, tool contracts, and structured output, with zero runtime overhead from the type layer.

## Create a Client

Import your server app type to get full inference.

```ts
import { createClient } from "@better-agent/client";
import type { app } from "./server";

const client = createClient<typeof app>({
  baseURL: "https://api.example.com",
  secret: process.env.BETTER_AGENT_SECRET!,
});
```

When your client and server are in separate packages, use the generated type from the CLI instead:

```ts
import { createClient } from "@better-agent/client";
import type { BAClientApp } from "./better-agent.types";

const client = createClient<BAClientApp>({
  baseURL: "https://api.example.com",
  secret: process.env.BETTER_AGENT_SECRET!,
});
```

| Field | Description |
| --- | --- |
| `baseURL` | Better Agent API base URL. Required. |
| `secret` | Bearer token sent with every request. Required. |
| `headers` | Default headers merged into every request. |
| `fetch` | Custom fetch implementation for environments without a global `fetch`. |

## run

`run` calls an agent and waits for the final result.

```ts
const result = await client.run("assistant", {
  input: "What is the weather in Tokyo?",
  conversationId: "conv_123",
});

console.log(result.response.finishReason);
console.log(result.response.output);
```

Pass per-request options to add an abort signal, override headers, or observe the raw response:

```ts
const controller = new AbortController();

const result = await client.run("assistant", { input: "Hello" }, {
  signal: controller.signal,
  headers: { "X-Request-Id": "req_abc" },
});
```

## stream

`stream` returns an async iterable of events plus a `result` promise.

```ts
const stream = client.stream("assistant", {
  input: "Summarize this document...",
});

for await (const event of stream.events) {
  if (event.type === "TEXT_MESSAGE_CONTENT") {
    process.stdout.write(event.delta);
  }
}

const result = await stream.result;
```

## Type Safety

The type parameter on `createClient` carries your full server definition. Agent names autocomplete and invalid names produce compile errors. The `context` field is validated against the agent's `contextSchema`. The `structured` field on the result infers from the agent's `outputSchema`. Client tool handler inputs are inferred from the tool's schema.

```ts
// compile error: "asistant" is not a valid agent name
await client.run("asistant", { input: "Hello" });

// context is typed from the agent's contextSchema
await client.run("support", {
  input: "Help me",
  context: { userId: "user_123", plan: "pro" },
});
```

See [TypeScript](/docs/concepts/typescript) for the full picture on cross-package type inference.
