# Client

The Better Agent client is a typed HTTP client for talking to a Better Agent server. It gives you full inference for agent names, context schemas, tool contracts, and structured output — with zero runtime overhead. The type parameter carries your entire server definition.

## Create a Client

Import your server app type to get full inference:

```ts
import { createClient } from "@better-agent/client";
import type { app } from "./server";

const client = createClient<typeof app>({
  baseURL: "https://api.example.com",
  secret: process.env.BETTER_AGENT_SECRET!,
});
```

When your client and server are in separate packages, use the type generated by the CLI:

```ts
import { createClient } from "@better-agent/client";
import type { BAClientApp } from "./better-agent.types";

const client = createClient<BAClientApp>({
  baseURL: "https://api.example.com",
  secret: process.env.BETTER_AGENT_SECRET!,
});
```

| Field | Description |
| --- | --- |
| `baseURL` | Better Agent API base URL. Required. |
| `secret` | Bearer token sent with every request. Required. |
| `headers` | Default headers merged into every request. |
| `fetch` | Custom fetch implementation for environments that need it. |

## run

Runs an agent and waits for the final result:

```ts
const result = await client.run("assistant", {
  input: "What is the weather in Tokyo?",
  conversationId: "conv_123",
});

console.log(result.response.finishReason);
console.log(result.response.output);
```

Per-request options let you pass an abort signal, override headers, or observe the raw response:

```ts
const controller = new AbortController();

const result = await client.run("assistant", { input: "Hello" }, {
  signal: controller.signal,
  headers: { "X-Request-Id": "req_abc" },
});
```

## Type Safety

The type parameter on `createClient` carries your full server definition. This gives you typed agent names (typos become compile errors), typed `context` validated against the agent's `contextSchema`, typed `structured` results from the agent's `outputSchema`, and typed `toolHandlers` with input inferred from each tool's schema.

```ts
// Compile error: "asistant" is not a valid agent name
await client.run("asistant", { input: "Hello" });

// Typed context from contextSchema
await client.run("support", {
  input: "Help me",
  context: { userId: "user_123", plan: "pro" },
});
```

See [TypeScript](/docs/concepts/typescript) for the full picture of what gets inferred and how to share types across packages.
