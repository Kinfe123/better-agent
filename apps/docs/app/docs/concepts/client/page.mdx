# Client

The Better Agent client is a typed HTTP client for talking to a Better Agent server. It gives you full inference for agent names, context schemas, tool contracts, and structured output, with zero runtime overhead.

## Create a Client

Import your server app type to get full inference.

```ts
import { createClient } from "@better-agent/client";
import type { app } from "./server";

const client = createClient<typeof app>({
  baseURL: "https://api.example.com",
  secret: process.env.BETTER_AGENT_SECRET!,
});
```

When your client and server are in separate packages, use the generated type from the CLI instead:

```ts
import { createClient } from "@better-agent/client";
import type { BAClientApp } from "./better-agent.types";

const client = createClient<BAClientApp>({
  baseURL: "https://api.example.com",
  secret: process.env.BETTER_AGENT_SECRET!,
});
```

| Field | Description |
| --- | --- |
| `baseURL` | Better Agent API base URL. Required. |
| `secret` | Bearer token sent with every request. Required. |
| `headers` | Default headers merged into every request. |
| `fetch` | Custom fetch implementation, useful for test mocks or edge environments. |

## Type Safety

The type parameter on `createClient` carries your full server definition. This gives you typed agent names (autocomplete and compile errors for invalid names), typed `context` validated against each agent's `contextSchema`, typed `structured` on run results, and typed tool handler inputs.

```ts
// TypeScript catches this at compile time:
// @ts-expect-error "asistant" is not a valid agent name
await client.run("asistant", { input: "Hello" });

// Context is typed per-agent:
await client.run("support", {
  input: "Help me",
  context: { userId: "user_123", plan: "pro" },
});
```

## run

Runs an agent and returns the final result.

```ts
const result = await client.run("assistant", {
  input: "What is the weather in Tokyo?",
  conversationId: "conv_123",
});

console.log(result.response.finishReason);
console.log(result.response.output);
```

Per-request options let you override headers, pass an abort signal, or observe the raw response.

```ts
const controller = new AbortController();

const result = await client.run("assistant", { input: "Hello" }, {
  signal: controller.signal,
  headers: { "X-Request-Id": "req_abc" },
});
```

## Framework Hooks

The client package includes framework-specific hooks that manage messages, status, and streaming state for you.

- **React**: `useAgent` from `@better-agent/client/react`
- **Vue**: `useAgent` from `@better-agent/client/vue`
- **Svelte**: `createAgentChat` from `@better-agent/client/svelte`
- **Solid**: `useAgent` from `@better-agent/client/solid`
- **Preact**: `useAgent` from `@better-agent/client/preact`
