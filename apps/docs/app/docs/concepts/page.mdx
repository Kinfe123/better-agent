# Concepts

This section covers the core building blocks of Better Agent. Each page focuses on one primitive and shows you how to use it with concrete examples.

Start with [Agent](/docs/concepts/agent) to understand the fundamental unit of behavior, then read [API](/docs/concepts/api) to see how an app is assembled and exposed over HTTP. [Tools](/docs/concepts/tools), [Providers](/docs/concepts/providers), [Events](/docs/concepts/events), [Persistence](/docs/concepts/persistence), and [Plugins](/docs/concepts/plugins) each cover one slice of the runtime. [CLI](/docs/concepts/cli) and [TypeScript](/docs/concepts/typescript) explain how type safety flows from server to client, especially across separate packages.
