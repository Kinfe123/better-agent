# Concepts

This section covers the primitives and mental models you need to build confidently with Better Agent.

Start with [Agent](/docs/concepts/agent) — the core unit of behavior — then read [Tools](/docs/concepts/tools) to understand how agents take structured actions and [Providers](/docs/concepts/providers) to connect those agents to model APIs. The [API](/docs/concepts/api) page covers how to expose your app over HTTP and call it programmatically. [Client](/docs/concepts/client) explains the typed HTTP client and framework hooks.

For advanced workflows, [Events](/docs/concepts/events) covers real-time streaming, [Persistence](/docs/concepts/persistence) covers durable conversations and stream resumption, [Human in the Loop](/docs/concepts/hil) covers approval flows, and [MCP](/docs/concepts/mcp) covers connecting agents to external tools over the Model Context Protocol.

[Structured Output](/docs/concepts/structured-output) and [TypeScript](/docs/concepts/typescript) cover the type-safety story end to end. [Plugins](/docs/concepts/plugins) explains the cross-agent extension system, and [Errors](/docs/concepts/errors) covers error codes and recovery patterns.
