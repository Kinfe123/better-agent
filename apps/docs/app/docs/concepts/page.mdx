# Concepts

This section covers the primitives you'll use every day with Better Agent. Each page focuses on one concept with concrete examples.

Start with [Agent](/docs/concepts/agent) to understand the core unit of behavior. Then read [API](/docs/concepts/api) to see how apps expose agents over HTTP, and [Client](/docs/concepts/client) to understand the typed client. From there, [Tools](/docs/concepts/tools), [Events](/docs/concepts/events), [Persistence](/docs/concepts/persistence), and [Plugins](/docs/concepts/plugins) cover the features you'll reach for as your app grows.
