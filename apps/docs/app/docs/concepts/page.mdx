# Concepts

The concepts section explains the primitives and mental models that underpin Better Agent. Read [Agent](/docs/concepts/agent) first — it's the core building block everything else connects to.

From there, [Tools](/docs/concepts/tools) explains how agents take structured actions. [Providers](/docs/concepts/providers) covers how models are wired in. [API](/docs/concepts/api) explains the HTTP layer and the programmatic `run` and `stream` methods. [Client](/docs/concepts/client) covers the typed HTTP client.

For production concerns: [Persistence](/docs/concepts/persistence) covers durable conversations and stream resumption. [Plugins](/docs/concepts/plugins) covers cross-agent behavior like auth, logging, and rate limiting. [Human in the Loop](/docs/concepts/hil) explains approval flows for sensitive tools. [Events](/docs/concepts/events) covers real-time observability during a run.

For cross-package type safety, see [TypeScript](/docs/concepts/typescript) and [CLI](/docs/concepts/cli).
