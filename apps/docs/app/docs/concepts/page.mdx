# Concepts

This section covers the primitives and mental models you need to work effectively with Better Agent. Read these pages in order if you're new, or jump to the one you need.

- [Agent](/docs/concepts/agent) — the core building block: a model, instructions, tools, and context schema combined into one typed definition
- [API](/docs/concepts/api) — how to create an app, mount its HTTP handler, and call it programmatically
- [Client](/docs/concepts/client) — the typed HTTP client and how to get full type inference from your server
- [TypeScript](/docs/concepts/typescript) — end-to-end type inference, same-project imports, and CLI-generated portable types
- [Tools](/docs/concepts/tools) — server tools, client tools, and hosted provider tools
- [Structured Output](/docs/concepts/structured-output) — validated, typed JSON responses from your agents
- [Events](/docs/concepts/events) — streaming run events and how to consume them
- [Persistence](/docs/concepts/persistence) — durable conversations, stream resumption, and runtime state stores
- [Plugins](/docs/concepts/plugins) — cross-agent behavior: guards, lifecycle hooks, and custom endpoints
- [Providers](/docs/concepts/providers) — connecting Better Agent to model APIs
- [MCP](/docs/concepts/mcp) — integrating external tools via the Model Context Protocol
- [Human in the Loop](/docs/concepts/hil) — pausing execution for human approval before a tool runs
- [Errors](/docs/concepts/errors) — error shapes, stable codes, and client-side normalization
- [CLI](/docs/concepts/cli) — generating portable type declarations from your app
