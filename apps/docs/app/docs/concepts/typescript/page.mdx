# TypeScript

Better Agent keeps your server and client in sync through TypeScript. Agent names, run context, structured output, and client tool handlers are inferred from your app definition — no manual type maintenance required.

Use a direct app type import in the same project, or generate a portable type with the [CLI](/docs/concepts/cli) when your client lives in a separate package.

## What Gets Inferred

Each part of your app definition becomes a typed contract on the client:

| Definition | Client Type |
| --- | --- |
| `agent.name` | String literal union for the `agent` parameter |
| `agent.contextSchema` | Typed `context` field on `run()` and `stream()` input |
| `agent.outputSchema` | Typed `structured` field on the run result |
| Client tools (`.client()`) | Typed `toolHandlers` map with handler input inferred from the tool's schema |
| `model.caps` | Capability-gated fields — `modalities`, `outputSchema`, etc. only appear when the model supports them |

## Same Project

When your client and server share the same TypeScript project, import the app type directly.

```ts
// server.ts
export const app = betterAgent({
  agents: [supportAgent],
});
```

```ts
// client.ts
import { createClient } from "@better-agent/client";
import type { app } from "./server";

const client = createClient<typeof app>({
  baseURL: "/api",
  secret: "dev-secret",
});
```

## Separate Packages

When your client and server live in different packages, use the CLI to generate a portable `.d.ts` file.

```bash
npx @better-agent/cli generate type --config ./server.ts
```

The output looks like this:

```ts
// better-agent.types.d.ts
export type BAClientApp = {
  config: {
    agents: readonly [{
      name: "support";
      model: { caps: { structured_output: true; multi_turn: true } };
      contextSchema: { userId: string; plan: "free" | "pro" };
      outputSchema: {
        schema: { reply: string; sentiment: "positive" | "negative" | "neutral" };
      };
    }];
  };
};
```

Import that type in your client package:

```ts
import type { BAClientApp } from "./better-agent.types";

const client = createClient<BAClientApp>({ baseURL: "...", secret: "..." });
```

No server code is imported. The type file is fully portable.
