# TypeScript

Better Agent keeps your server and client in sync through TypeScript. Agent names, run context, structured output, and client tool handlers are inferred from your app definition. A typo in an agent name or a wrong context shape is a compile error, not a runtime failure.

## What You Get

Each part of your app definition becomes a typed contract on the client:

| Definition | Client Type |
| --- | --- |
| `agent.name` | String literal union for the `agent` parameter |
| `agent.contextSchema` | Typed `context` field on `run()` and `stream()` input |
| `agent.outputSchema` | Typed `structured` field on the run result |
| Client tools (`.client()`) | Typed `toolHandlers` map with input inferred from the tool's schema |
| `model.caps` | Capability-gated fields — `modalities`, `outputSchema`, etc. only appear when the model supports them |

## Same Project

When your client and server share the same TypeScript project, import the app type directly.

```ts
// server.ts
import { defineAgent, betterAgent } from "@better-agent/core";
import { z } from "zod";
import { openai } from "./openai";

const supportAgent = defineAgent({
  name: "support",
  model: openai.model("gpt-4o"),
  contextSchema: z.object({
    userId: z.string(),
    plan: z.enum(["free", "pro"]),
  }),
  outputSchema: {
    schema: z.object({
      reply: z.string(),
      sentiment: z.enum(["positive", "negative", "neutral"]),
    }),
  },
});

export const app = betterAgent({ agents: [supportAgent] });
```

```ts
// client.ts
import { createClient } from "@better-agent/client";
import type { app } from "./server";

const client = createClient<typeof app>({
  baseURL: "/api",
  secret: "dev-secret",
});

const result = await client.run("support", {
  input: "I need help",
  context: { userId: "u_1", plan: "pro" },
});

console.log(result.structured.reply);
console.log(result.structured.sentiment);
```

## Separate Packages

When your client and server live in different packages, generate a portable `.d.ts` file with the CLI:

```bash
npx @better-agent/cli generate type --config ./server.ts
```

This produces a `better-agent.types.d.ts` file containing the full app type. Import it on the client to get the same inference without importing any server code.

```ts
import { createClient } from "@better-agent/client";
import type { BAClientApp } from "./better-agent.types";

const client = createClient<BAClientApp>({
  baseURL: "https://api.example.com",
  secret: process.env.BETTER_AGENT_SECRET!,
});
```

See [CLI](/docs/concepts/cli) for all CLI options and how to customize the output path and type alias name.
