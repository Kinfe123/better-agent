# Documentation Lookup

Documentation lookup finds relevant docs context before the project answers a user question.
## What You Can Do
This workflow turns a user question into usable documentation context. It sends the question to the configured documentation source, parses the returned sections, keeps useful metadata such as titles and source links, and hands the best context to the response step.
## Key Ideas
- docs retrieval
- query text
- source links
- code examples
- empty-result fallback
## How It Works
1. Receive a question from the runtime, bot, CLI, or web UI.
2. Fetch matching documentation sections from the configured docs source.
3. Keep enough source context for the answer step to explain where the guidance came from.
## Behavior Details
- The lookup step calls an external documentation source such as `https://better-agent.com/docs/concepts/errors`.
- Returned docs are shaped into reader-friendly fields such as title, description, source link, language, and code example.
