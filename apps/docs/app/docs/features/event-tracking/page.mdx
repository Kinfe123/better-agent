# Event Tracking

Event tracking turns runtime activity into timelines, audit trails, and last-seen context.
## What You Can Do
This capability turns runtime activity into a timeline that administrators can inspect. It is especially useful for auth products because sign-ins, session creation, account updates, and organization events often need auditability and context.

Better Agent is a TypeScript framework for building typed, event driven, framework agnostic agent applications.  It provides structure for agents, tools, approvals, persistence, streaming, and typed clients without forcing a fixed application model.
