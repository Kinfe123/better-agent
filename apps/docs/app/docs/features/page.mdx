# Features

These pages cover features for Better Agent.

## When to Use This Section
Feature pages explain the capabilities Better Agent exposes to users, operators, or application developers. Each page starts with the outcome, then links that behavior to setup and reference details.

## Available Pages
- [AI Responses](/docs/features/ai-responses) - AI responses turn retrieved context into a concise answer for the person asking the question.
- [Conversation Memory](/docs/features/conversation-memory) - Conversation memory keeps recent messages so follow-up questions can use nearby context.
- [Developer Tools](/docs/features/developer-tools) - Developer tools help configure, inspect, and generate the pieces needed to run the product.
- [Documentation Lookup](/docs/features/documentation-lookup) - Documentation lookup finds relevant docs context before the project answers a user question.
- [Event Tracking](/docs/features/event-tracking) - Event tracking turns runtime activity into timelines, audit trails, and last-seen context.
- [Session Management](/docs/features/session-management) - Session management explains active authentication state, sign-in activity, and session controls.

## Reading Order
- Start with the page closest to the workflow you are trying to complete.
- Use setup and configuration pages before running commands in a new environment.
- Use reference pages when you already know the concept and need exact commands, imports, or options.
