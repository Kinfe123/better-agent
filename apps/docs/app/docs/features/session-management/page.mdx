# Session Management

Session management explains active authentication state, sign-in activity, and session controls.
## What You Can Do
This area explains how the product observes active authentication state. It connects user identity, session creation, sign-in activity, cookies or tokens, and any security-sensitive controls exposed to administrators.
## Key Ideas
- sessions
- sign in
- tokens
- cookies
- auth state

## How It Works
1. Review session records for a user or the whole workspace.
2. Use session metadata to understand device, location, or activity context when available.
3. Document any destructive session action with its security impact before exposing it to operators.
