# Get Started

Better Agent is a TypeScript framework for building typed, event-driven agent apps. This section takes you from zero to a working app with a real model, a typed client, and a UI.

Start with [Introduction](/docs/get-started/introduction) to understand the design goals. Then follow [Installation](/docs/get-started/installation) to set up the packages, and [Usage](/docs/get-started/usage) to build your first agent, client, and chat UI.
