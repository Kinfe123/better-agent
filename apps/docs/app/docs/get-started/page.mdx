# Get Started

Better Agent is a TypeScript framework for building typed, event-driven, framework-agnostic agent apps. These pages take you from installation through your first working app and into the concepts you need to go further.

Start with [Introduction](/docs/get-started/introduction) to understand why Better Agent exists and what it gives you. Then follow [Installation](/docs/get-started/installation) to get the packages set up. Once the packages are installed, [Usage](/docs/get-started/usage) walks you through a working server, typed client, and UI in under 50 lines of code.
