# Get Started

Better Agent is a TypeScript framework for building typed, event-driven agent apps. This section gets you from zero to a running agent in three steps.

Start with [Introduction](/docs/get-started/introduction) for a quick summary of what Better Agent is and why it exists. Then follow [Installation](/docs/get-started/installation) to add the packages to your project, and [Usage](/docs/get-started/usage) to build a server, typed client, and UI.

Once you have something running, the [Concepts](/docs/concepts) section covers the mental model behind agents, tools, providers, events, and persistence.
