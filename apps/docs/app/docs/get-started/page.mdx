# Get Started

Better Agent is a TypeScript framework for building typed, event-driven agent apps. These pages walk you from zero to a working app.

Start with [Introduction](/docs/get-started/introduction) to understand what Better Agent is and why it exists. Then follow [Installation](/docs/get-started/installation) to get the packages in place, and [Usage](/docs/get-started/usage) to build your first agent, client, and UI.
