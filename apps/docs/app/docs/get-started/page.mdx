# Get Started

Better Agent is a TypeScript framework for building typed, event-driven agent apps that fit into any server stack. This section covers everything you need to go from zero to a working app.

Start with [Introduction](/docs/get-started/introduction) for an overview of what Better Agent is and why it exists. Then follow [Installation](/docs/get-started/installation) to add the packages to your project — or run `npm create better-agent` to scaffold everything automatically. The [Usage](/docs/get-started/usage) page has a minimal working example with a server, typed client, and UI component you can copy and run immediately.
