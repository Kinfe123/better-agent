# Get Started

Better Agent is a TypeScript framework for building typed, event-driven agent apps. These pages take you from zero to a working agent app with a typed client and UI.

Start with [Introduction](/docs/get-started/introduction) to understand what Better Agent is and why it's designed the way it is. Then follow [Installation](/docs/get-started/installation) to add the packages to your project, and [Usage](/docs/get-started/usage) to build your first working app.
