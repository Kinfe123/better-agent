# Get Started

Better Agent is a TypeScript framework for building typed, event-driven, framework-agnostic agent apps. This section covers everything you need to go from zero to a working agent app.

Start with [Introduction](/docs/get-started/introduction) for the why behind the framework, then [Installation](/docs/get-started/installation) to get the packages in place, then [Usage](/docs/quickstart) for a minimal working example you can run immediately.
