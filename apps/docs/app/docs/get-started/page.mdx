# Get Started

Better Agent is a TypeScript framework for building typed, event-driven, framework-agnostic agent apps. This section covers everything you need to go from zero to a working agent app.

Start with [Introduction](/docs/get-started/introduction) if you want to understand the design goals and major features before writing any code. Go to [Installation](/docs/get-started/installation) to scaffold a new project or add Better Agent to an existing one. Then follow [Usage](/docs/get-started/usage) to build your first server, typed client, and UI in a few minutes.
