# Usage

This page walks you through a minimal Better Agent app: a server module with one agent, a typed client, and a React UI. The same shape scales to tools, structured output, and persistence without changing its structure.

## Define the Server

Create a Better Agent app with one agent in `server.ts`.

```ts
import { betterAgent, defineAgent } from "@better-agent/core";
import { createOpenAI } from "@better-agent/providers/openai";

const openai = createOpenAI({
  apiKey: process.env.OPENAI_API_KEY,
});

const helloAgent = defineAgent({
  name: "helloAgent",
  model: openai.text("gpt-4o-mini"),
  instruction: "You are a friendly assistant. Keep answers short.",
});

const app = betterAgent({
  agents: [helloAgent],
  baseURL: "/api",
  secret: process.env.BETTER_AGENT_SECRET,
});

export default app;
```

## Create a Typed Client

Import the server app type to give the client full inference over agent names, inputs, and outputs.

```ts
import { createClient } from "@better-agent/client";
import type app from "./server";

export const client = createClient<typeof app>({
  baseURL: "/api",
  secret: process.env.BETTER_AGENT_SECRET!,
});
```

When your client and server live in separate packages, use the generated type from the CLI instead. See [TypeScript](/docs/concepts/typescript) for details.

## Connect the UI

Use `useAgent` from `@better-agent/client/react` to wire up a chat loop.

```tsx
import { useState } from "react";
import { useAgent } from "@better-agent/client/react";
import { client } from "./client";

export default function Page() {
  const [input, setInput] = useState("");

  const { messages, status, sendMessage } = useAgent(client, {
    agent: "helloAgent",
  });

  return (
    <div>
      <ul>
        {messages.map((message) => (
          <li key={message.localId}>
            <strong>{message.role}:</strong>{" "}
            {message.parts
              .map((part) => (part.type === "text" ? part.text : ""))
              .join("")}
          </li>
        ))}
      </ul>
      <input value={input} onChange={(e) => setInput(e.target.value)} />
      <button
        disabled={status === "streaming"}
        onClick={() => { sendMessage(input); setInput(""); }}
      >
        Send
      </button>
    </div>
  );
}
```

From here you can add [Tools](/docs/concepts/tools) to let the agent take actions, [Structured Output](/docs/concepts/structured-output) for typed JSON responses, and [Persistence](/docs/concepts/persistence) for durable multi-turn conversations.
