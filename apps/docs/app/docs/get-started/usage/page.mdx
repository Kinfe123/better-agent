# Usage

This page builds a minimal Better Agent app across three files: `server.ts` defines the agent, `client.ts` creates the typed client, and a UI component drives the conversation.

## Define the server

Create a Better Agent app with one agent. At minimum an agent needs a name and a model.

```ts
import { betterAgent, defineAgent } from "@better-agent/core";
import { createOpenAI } from "@better-agent/providers/openai";

const openai = createOpenAI({
  apiKey: process.env.OPENAI_API_KEY,
});

const helloAgent = defineAgent({
  name: "helloAgent",
  model: openai.text("gpt-4o-mini"),
  instruction: "You are a friendly assistant. Keep answers short.",
});

const app = betterAgent({
  agents: [helloAgent],
  baseURL: "/api",
  secret: process.env.BETTER_AGENT_SECRET,
});

export default app;
```

## Create a typed client

Import your server app type to get full inference. Agent names, inputs, outputs, tools, and context all flow through to the client.

```ts
import { createClient } from "@better-agent/client";
import type app from "./server";

export const client = createClient<typeof app>({
  baseURL: "/api",
  secret: process.env.BETTER_AGENT_SECRET!,
});
```

> **Note:** When your client and server live in separate packages, use `@better-agent/cli` to generate a portable `.d.ts` type file. See [CLI](/docs/concepts/cli) for details.

## Connect the UI

Use the `useAgent` hook from `@better-agent/client/react` to wire up the conversation. The hook manages messages, status, and streaming.

```tsx
import { useState } from "react";
import { useAgent } from "@better-agent/client/react";
import { client } from "./client";

export default function Page() {
  const [input, setInput] = useState("");

  const { messages, status, sendMessage } = useAgent(client, {
    agent: "helloAgent",
  });

  return (
    <div>
      <ul>
        {messages.map((message) => (
          <li key={message.localId}>
            <strong>{message.role}:</strong>{" "}
            {message.parts
              .map((part) => (part.type === "text" ? part.text : ""))
              .join("")}
          </li>
        ))}
      </ul>
      <input
        value={input}
        onChange={(e) => setInput(e.target.value)}
        disabled={status === "running"}
      />
      <button onClick={() => { sendMessage(input); setInput(""); }}>
        Send
      </button>
    </div>
  );
}
```

Vue, Svelte, Solid, and Preact adapters are available from `@better-agent/client/vue`, `@better-agent/client/svelte`, `@better-agent/client/solid`, and `@better-agent/client/preact` respectively.
