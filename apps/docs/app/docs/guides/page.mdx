# Guides

These pages cover guides for Better Agent.

## When to Use This Section
Guides provide task-oriented paths through Better Agent. They start from the reader's goal, then connect the required commands, configuration, and verification steps.

## Available Pages
- [CLI Usage](/docs/guides/cli-usage) - CLI usage explains the commands and flags developers use to initialize, run, and debug the product.

## Reading Order
- Start from the guide that matches the job you are trying to finish.
- Follow prerequisite and verification steps before jumping to reference pages.
- Use API and configuration pages when a guide mentions a command, option, or runtime setting.
