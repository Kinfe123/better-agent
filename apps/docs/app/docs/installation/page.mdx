# Installation

Better Agent is installed automatically via the `create` CLI or manually by adding packages to an existing TypeScript project.

## Automatic

The fastest way to start is with the create CLI. It detects your framework, generates the Better Agent files, lets you choose providers and plugins, and writes the required environment variables and package entries.

```bash
npm create better-agent
```

```bash
pnpm create better-agent
```

```bash
yarn create better-agent
```

```bash
bun create better-agent
```

To patch Better Agent into an existing project instead of scaffolding a new one:

```bash
npm create better-agent@latest -- --mode patch
```

The CLI supports `generic`, `nextjs`, `remix`, `sveltekit`, `astro`, `nuxt`, `tanstack-start`, `solidstart`, and `react-router`.

## Manual

If you prefer full control over the project structure, install the packages directly.

**Core** — agents, tools, events, and runtime primitives:

```bash
npm install @better-agent/core
```

**Client** — typed HTTP client plus framework hooks for React, Vue, Svelte, Solid, and Preact:

```bash
npm install @better-agent/client
```

**Providers** — adapters for OpenAI, Anthropic, and xAI:

```bash
npm install @better-agent/providers
```

**Plugins** — guards, lifecycle hooks, middleware, and runtime extensions:

```bash
npm install @better-agent/plugins
```

**CLI** — type generation for client packages and app definitions:

```bash
npm install -D @better-agent/cli
```

> **Note:** Better Agent requires TypeScript. If your project does not have it yet, run `npm install typescript -D && npx tsc --init` first.
