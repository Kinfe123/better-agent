# Auth

The auth plugin blocks requests unless they provide a valid API key. Use static keys for simple setups, or provide your own validation logic for keys that come from a database or external service.

## Basic usage

By default the plugin reads the key from the `x-api-key` header:

```ts
import { authPlugin } from "@better-agent/plugins";

const plugin = authPlugin({
  apiKeys: ["dev-key"],
});
```

## Custom header

Use `header` when your key lives in a different header:

```ts
const plugin = authPlugin({
  header: "authorization",
  apiKeys: ["Bearer dev-key"],
});
```

## Custom validation

Use `getKey` and `validate` when you need your own auth logic — for example, when keys come from your database or when validation is agent-specific:

```ts
const plugin = authPlugin({
  getKey: ({ request }) => request.headers.get("authorization"),
  validate: async ({ key, agentName }) => {
    const record = await db.apiKeys.findUnique({ where: { key } });
    return record !== null;
  },
});
```

## Register the plugin

Add the plugin to your `betterAgent()` config:

```ts
import { betterAgent } from "@better-agent/core";
import { authPlugin } from "@better-agent/plugins";

export const app = betterAgent({
  agents: [myAgent],
  plugins: [authPlugin({ apiKeys: [process.env.BETTER_AGENT_API_KEY!] })],
});
```

If validation fails, the plugin returns `401 Unauthorized` and the request is rejected before reaching the agent.
