# Plugins

Better Agent ships a set of ready-made plugins for the most common cross-agent needs. Register them once at the app level and they apply to every agent automatically.

[Auth](/docs/plugins/auth) blocks requests unless they provide a valid API key. It supports static key lists, custom headers, and fully custom validation logic for keys that live in your own database.

For building custom plugins or understanding the plugin lifecycle in depth, see [Concepts: Plugins](/docs/concepts/plugins).
