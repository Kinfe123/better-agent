# Plugins

Plugins is the starting point for related workflows in create-better-agent. Choose the page that matches the workflow, integration, or reference surface you need, then follow its setup and verification guidance.

## When to Use This Section
- Start with the page closest to the workflow you are trying to complete.
- Use setup and configuration pages before running commands in a new environment.
- Use reference pages when you already know the concept and need exact commands, imports, or options.

## Available Pages
- [Auth](/docs/plugins/auth) - API key auth plugin with static keys or custom validation.
- [IP Allowlist](/docs/plugins/ip-allowlist) - IP allowlist plugin with exact IPs, CIDR ranges, and proxy-aware resolution.
- [Logging](/docs/plugins/logging) - Structured runtime logging plugin with filtering, redaction, and custom formatting.
- [Rate Limit](/docs/plugins/rate-limit) - Rate limiting plugin using windowed counters with optional custom storage.
- [Sandbox](/docs/plugins/sandbox) - Give your agents a real workspace to run code, edit files, and preview apps.
