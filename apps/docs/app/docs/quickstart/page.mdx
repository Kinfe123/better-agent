# Quickstart

This page walks you through building a minimal Better Agent app: a server that defines an agent, a typed client that connects to it, and a React UI that drives the conversation. The same shape applies to every framework Better Agent supports.

## Define the server

Create `server.ts` with a single agent. You need a name, a model, and an instruction.

```ts
import { betterAgent, defineAgent } from "@better-agent/core";
import { createOpenAI } from "@better-agent/providers/openai";

const openai = createOpenAI({
  apiKey: process.env.OPENAI_API_KEY,
});

const helloAgent = defineAgent({
  name: "helloAgent",
  model: openai.text("gpt-4o-mini"),
  instruction: "You are a friendly assistant. Keep answers short.",
});

const app = betterAgent({
  agents: [helloAgent],
  baseURL: "/api",
  secret: process.env.BETTER_AGENT_SECRET,
});

export default app;
```

## Create a typed client

Import your server app type to get full inference. Agent names, context schemas, structured output, and tool handlers all flow through to the client automatically.

```ts
import { createClient } from "@better-agent/client";
import type app from "./server";

export const client = createClient<typeof app>({
  baseURL: "/api",
  secret: process.env.BETTER_AGENT_SECRET!,
});
```

> **Note:** When your client and server live in separate packages, use `@better-agent/cli` to generate a portable `.d.ts` file instead of importing the server type directly. See [CLI](/docs/concepts/cli) for details.

## Connect the UI

Use the `useAgent` hook from `@better-agent/client/react` to wire up the conversation loop. The hook manages messages, status, and streaming for you.

```tsx
import { useState } from "react";
import { useAgent } from "@better-agent/client/react";
import { client } from "./client";

export default function Page() {
  const [input, setInput] = useState("");

  const { messages, status, sendMessage } = useAgent(client, {
    agent: "helloAgent",
  });

  return (
    <div>
      <ul>
        {messages.map((message) => (
          <li key={message.localId}>
            <strong>{message.role}:</strong>{" "}
            {message.parts
              .map((part) => (part.type === "text" ? part.text : ""))
              .join("")}
          </li>
        ))}
      </ul>
      <input
        value={input}
        onChange={(e) => setInput(e.target.value)}
        disabled={status === "running"}
      />
      <button onClick={() => { sendMessage(input); setInput(""); }}>
        Send
      </button>
    </div>
  );
}
```

## Mount the route

In Next.js App Router, create a catch-all route at `app/api/[...path]/route.ts` and forward the request to Better Agent:

```ts
import app from "@/server";

export const GET = (req: Request) => app.handler(req);
export const POST = (req: Request) => app.handler(req);
```

Keep the route path aligned with `baseURL` in your `betterAgent()` config. Other framework integrations follow the same pattern — see the integrations pages for framework-specific examples.
