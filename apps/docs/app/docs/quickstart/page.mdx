# Quickstart

This page walks you through a minimal Better Agent app: a server with one agent, a typed client, and a React UI that sends messages. The same shape works for every supported framework.

## Define the server

Create a `server.ts` file with one agent registered in a Better Agent app:

```ts
import { betterAgent, defineAgent } from "@better-agent/core";
import { createOpenAI } from "@better-agent/providers/openai";

const openai = createOpenAI({
  apiKey: process.env.OPENAI_API_KEY,
});

const helloAgent = defineAgent({
  name: "helloAgent",
  model: openai.text("gpt-4o-mini"),
  instruction: "You are a friendly assistant. Keep answers short.",
});

const app = betterAgent({
  agents: [helloAgent],
  baseURL: "/api",
  secret: process.env.BETTER_AGENT_SECRET,
});

export default app;
```

## Create a typed client

Import your server app type so agent names, inputs, outputs, and tools stay aligned with your backend:

```ts
import { createClient } from "@better-agent/client";
import type app from "./server";

export const client = createClient<typeof app>({
  baseURL: "/api",
  secret: process.env.BETTER_AGENT_SECRET!,
});
```

When your client and server live in separate packages, generate a portable type file with the CLI instead of importing directly:

```bash
npx @better-agent/cli generate type --config ./server.ts
```

## Connect the UI

Use `useAgent` from the React adapter to wire up the chat loop:

```tsx
import { useState } from "react";
import { useAgent } from "@better-agent/client/react";
import { client } from "./client";

export default function Page() {
  const [input, setInput] = useState("");

  const { messages, status, sendMessage } = useAgent(client, {
    agent: "helloAgent",
  });

  return (
    <div>
      <ul>
        {messages.map((message) => (
          <li key={message.localId}>
            <strong>{message.role}:</strong>{" "}
            {message.parts
              .map((part) => (part.type === "text" ? part.text : ""))
              .join("")}
          </li>
        ))}
      </ul>
      <input value={input} onChange={(e) => setInput(e.target.value)} />
      <button onClick={() => { sendMessage(input); setInput(""); }}>
        Send
      </button>
      <p>Status: {status}</p>
    </div>
  );
}
```

> **Note:** Framework adapters exist for Vue, Svelte, Solid, and Preact as well — all exported from `@better-agent/client/<framework>`.

## Next steps

From here you can add tools with `defineTool()`, structured output with `outputSchema`, or durable conversations with a persistence store. Read [Agent](/docs/concepts/agent) to understand the full agent definition, or [Tools](/docs/concepts/tools) to give your agent something to do.
