# Quickstart

This page walks you through a minimal Better Agent app: a server that defines one agent, a typed client that mirrors it, and a React component that talks to both. The same shape scales to tools, structured output, and persistence without changing the structure.

## Define the server

Create a Better Agent app with one agent in `server.ts`. The `betterAgent()` call produces both a programmatic API and a standard HTTP handler you can mount anywhere.

```ts
import { betterAgent, defineAgent } from "@better-agent/core";
import { createOpenAI } from "@better-agent/providers/openai";

const openai = createOpenAI({
  apiKey: process.env.OPENAI_API_KEY,
});

const helloAgent = defineAgent({
  name: "helloAgent",
  model: openai.text("gpt-4o-mini"),
  instruction: "You are a friendly assistant. Keep answers short.",
});

const app = betterAgent({
  agents: [helloAgent],
  baseURL: "/api",
  secret: process.env.BETTER_AGENT_SECRET,
});

export default app;
```

## Create a typed client

Import the server app type to get full inference for agent names, context, and output shapes.

```ts
import { createClient } from "@better-agent/client";
import type app from "./server";

export const client = createClient<typeof app>({
  baseURL: "/api",
  secret: process.env.BETTER_AGENT_SECRET!,
});
```

When your client and server live in separate packages, use the type generated by the CLI instead. See [TypeScript](/docs/concepts/typescript) for details.

## Connect the UI

Use `useAgent` from `@better-agent/client/react` to wire the client into a React component. The hook manages messages, status, and the send function for you.

```tsx
import { useState } from "react";
import { useAgent } from "@better-agent/client/react";
import { client } from "./client";

export default function Page() {
  const [input, setInput] = useState("");
  const { messages, status, sendMessage } = useAgent(client, {
    agent: "helloAgent",
  });

  return (
    <div>
      <ul>
        {messages.map((msg) => (
          <li key={msg.localId}>
            <strong>{msg.role}:</strong>{" "}
            {msg.parts
              .map((p) => (p.type === "text" ? p.text : ""))
              .join("")}
          </li>
        ))}
      </ul>
      <input value={input} onChange={(e) => setInput(e.target.value)} />
      <button
        disabled={status === "streaming"}
        onClick={() => { sendMessage(input); setInput(""); }}
      >
        Send
      </button>
    </div>
  );
}
```

> **Note:** Framework adapters for Vue, Svelte, Solid, and Preact follow the same pattern with their own import paths.
