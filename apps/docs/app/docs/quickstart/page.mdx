# Quickstart

This page walks you through building a small Better Agent app: a server with one agent, a typed client, and a React UI component. You can adapt the same shape to any supported framework.

## Define the server

Create a Better Agent app with one agent in `server.ts`:

```ts
import { betterAgent, defineAgent } from "@better-agent/core";
import { createOpenAI } from "@better-agent/providers/openai";

const openai = createOpenAI({
  apiKey: process.env.OPENAI_API_KEY,
});

const helloAgent = defineAgent({
  name: "helloAgent",
  model: openai.text("gpt-4o-mini"),
  instruction: "You are a friendly assistant. Keep answers short.",
});

const app = betterAgent({
  agents: [helloAgent],
  baseURL: "/api",
  secret: "dev-secret",
});

export default app;
```

## Create a typed client

Import your server app type to get full inference for agent names, context schemas, and structured output:

```ts
import { createClient } from "@better-agent/client";
import type app from "./server";

export const client = createClient<typeof app>({
  baseURL: "/api",
  secret: "dev-secret",
});
```

When your client and server live in different packages, use the generated type from the CLI instead. See [TypeScript](/docs/concepts/typescript) for details.

## Connect the UI

Use `useAgent` from the React adapter to wire up a chat component:

```tsx
import { useState } from "react";
import { useAgent } from "@better-agent/client/react";
import { client } from "./client";

export default function Page() {
  const [input, setInput] = useState("");

  const { messages, status, sendMessage } = useAgent(client, {
    agent: "helloAgent",
  });

  return (
    <div>
      <ul>
        {messages.map((message) => (
          <li key={message.localId}>
            {message.role}:{" "}
            {message.parts
              .map((part) => (part.type === "text" ? part.text : ""))
              .join("")}
          </li>
        ))}
      </ul>
      <input value={input} onChange={(e) => setInput(e.target.value)} />
      <button onClick={() => { sendMessage(input); setInput(""); }}>
        Send
      </button>
      <p>Status: {status}</p>
    </div>
  );
}
```

Framework adapters for Vue, Svelte, Solid, and Preact follow the same `useAgent` pattern with framework-specific reactive primitives.
