# Quickstart

This page walks you through a minimal Better Agent app: a server with one agent, a typed client, and a React UI that streams responses. The same shape applies to every framework Better Agent supports.

## Define the server

Create a Better Agent app with one agent in `server.ts`.

```ts
import { betterAgent, defineAgent } from "@better-agent/core";
import { createOpenAI } from "@better-agent/providers/openai";

const openai = createOpenAI({
  apiKey: process.env.OPENAI_API_KEY,
});

const helloAgent = defineAgent({
  name: "helloAgent",
  model: openai.text("gpt-4o-mini"),
  instruction: "You are a friendly assistant. Keep answers short.",
});

const app = betterAgent({
  agents: [helloAgent],
  baseURL: "/api",
  secret: process.env.BETTER_AGENT_SECRET,
});

export default app;
```

## Create a typed client

Import the server app type to get full inference — agent names, context schemas, structured output, and tool contracts all flow through.

```ts
import { createClient } from "@better-agent/client";
import type app from "./server";

export const client = createClient<typeof app>({
  baseURL: "/api",
  secret: process.env.BETTER_AGENT_SECRET!,
});
```

When your client and server live in separate packages, use the generated type from the CLI instead. See [CLI](/docs/concepts/cli) for details.

## Connect the UI

Use `useAgent` from the React adapter to wire the client into a component.

```tsx
import { useState } from "react";
import { useAgent } from "@better-agent/client/react";
import { client } from "./client";

export default function Page() {
  const [input, setInput] = useState("");
  const { messages, status, sendMessage } = useAgent(client, {
    agent: "helloAgent",
  });

  return (
    <div>
      <ul>
        {messages.map((message) => (
          <li key={message.localId}>
            {message.role}:{" "}
            {message.parts
              .map((part) => (part.type === "text" ? part.text : ""))
              .join("")}
          </li>
        ))}
      </ul>
      <p>Status: {status}</p>
      <input value={input} onChange={(e) => setInput(e.target.value)} />
      <button onClick={() => { sendMessage(input); setInput(""); }}>
        Send
      </button>
    </div>
  );
}
```

Framework adapters for Vue, Svelte, Solid, and Preact follow the same pattern — swap the import path for `@better-agent/client/vue`, `@better-agent/client/svelte`, and so on.
