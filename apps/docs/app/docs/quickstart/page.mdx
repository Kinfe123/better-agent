# Quickstart

This page walks you through the minimal three-file shape every Better Agent app follows: a server module, a typed client, and a UI component. By the end you'll have a working chat loop that streams responses from a real model.

## Define the server

Create a Better Agent app with one agent in `server.ts`:

```ts
import { betterAgent, defineAgent } from "@better-agent/core";
import { createOpenAI } from "@better-agent/providers/openai";

const openai = createOpenAI({
  apiKey: process.env.OPENAI_API_KEY,
});

const helloAgent = defineAgent({
  name: "helloAgent",
  model: openai.text("gpt-4o-mini"),
  instruction: "You are a friendly assistant. Keep answers short.",
});

const app = betterAgent({
  agents: [helloAgent],
  baseURL: "/api",
  secret: process.env.BETTER_AGENT_SECRET,
});

export default app;
```

## Create a typed client

Import the server app type to get full inference over agent names, inputs, outputs, and tool contracts:

```ts
import { createClient } from "@better-agent/client";
import type app from "./server";

export const client = createClient<typeof app>({
  baseURL: "/api",
  secret: process.env.BETTER_AGENT_SECRET!,
});
```

When your client and server live in separate packages, use the [CLI](/docs/concepts/cli) to generate a portable `.d.ts` file instead of importing the server type directly.

## Connect the UI

Use `useAgent` from the React adapter to wire up a minimal chat loop:

```tsx
import { useState } from "react";
import { useAgent } from "@better-agent/client/react";
import { client } from "./client";

export default function Page() {
  const [input, setInput] = useState("");

  const { messages, status, sendMessage } = useAgent(client, {
    agent: "helloAgent",
  });

  return (
    <div>
      <ul>
        {messages.map((msg) => (
          <li key={msg.localId}>
            <strong>{msg.role}:</strong>{" "}
            {msg.parts
              .map((p) => (p.type === "text" ? p.text : ""))
              .join("")}
          </li>
        ))}
      </ul>
      <input value={input} onChange={(e) => setInput(e.target.value)} />
      <button
        onClick={() => {
          sendMessage(input);
          setInput("");
        }}
        disabled={status === "running"}
      >
        Send
      </button>
    </div>
  );
}
```

Framework adapters are available for Vue, Svelte, Solid, and Preact too — the `useAgent` pattern is the same across all of them.

From here, add [Tools](/docs/concepts/tools) to let the agent act on your data, use [Structured Output](/docs/concepts/structured-output) to get typed responses, or wire up [Persistence](/docs/concepts/persistence) for durable multi-turn conversations.
