# Astro Setup

Astro setup shows how to mount the product inside an Astro host application.
## What You Are Wiring
This setup page explains how to run the product inside an Astro application. It covers the runtime dependency, the framework route or server hook, and the configuration the host app must provide.
## Key Ideas
- Astro
- self-hosting
- runtime dependency
- route mount
- host app config
## Runtime Shape
This page focuses on the Astro runtime path provided by adapters, examples, or package exports.
Use `better-agent/astro` when wiring this runtime from the package export.
## Integration Story
For Astro, the important idea is that the host application owns runtime state, database access, routing, and deployment. Better Agent provides the handler or adapter that plugs into that host application. This page makes that boundary clear so developers know what the package supplies and what their app must still configure.
## Setup Checklist
1. Install dependencies with `bun install`.
2. Configure required environment variables before starting the runtime.
3. Run `bun run dev` or the framework-specific command from the host app.
4. Verify the mounted route, API handler, or container can reach the same runtime and database configuration as the host app.
## Configuration Files
- `examples/astro/astro.config.mjs` (framework) - Astro application configuration.
- `packages/create/templates/astro/base/astro.config.mjs` (framework) - Astro application configuration.
- `examples/astro/package.json` (package) - Package metadata, scripts, dependencies, and exports.
- `examples/astro/postcss.config.mjs` (styling) - Styling and CSS pipeline configuration.
- `packages/create/templates/astro/base/package.json` (package) - Package metadata, scripts, dependencies, and exports.
- `packages/create/templates/astro/base/postcss.config.mjs` (styling) - Styling and CSS pipeline configuration.
## Environment Variables
- `BA_DEBUG`
- `HOME`
- `OPENAI_API_KEY` - OpenAI API key used when the project generates AI answers from retrieved context.
- `OPENAI_BASE_URL` - URL used by the runtime to reach an external service, app, or callback endpoint.
