# Express Setup

Express setup shows how to mount the product inside an Express host application.
## What You Are Wiring
This setup page explains how to run the product inside an Express application. It covers the runtime dependency, the framework route or server hook, and the configuration the host app must provide.
## Key Ideas
- Express
- self-hosting
- runtime dependency
- route mount
- host app config
## Runtime Shape
This page focuses on the Express runtime path provided by adapters, examples, or package exports.
Use `better-agent/express` when wiring this runtime from the package export.
## Integration Story
For Express, the important idea is that the host application owns runtime state, database access, routing, and deployment. Better Agent provides the handler or adapter that plugs into that host application. This page makes that boundary clear so developers know what the package supplies and what their app must still configure.
## Setup Checklist
1. Install dependencies with `bun install`.
2. Configure required environment variables before starting the runtime.
3. Run `bun run dev` or the framework-specific command from the host app.
4. Verify the mounted route, API handler, or container can reach the same runtime and database configuration as the host app.

- `BA_DEBUG`
- `HOME`
