# Concepts

The concepts section explains every core primitive in Better Agent. Read these pages when you need to understand how the pieces fit together, not just how to call an API.

Start with [Agent](/docs/concepts/agent) — the fundamental building block that ties a model, instruction, tools, and context into one typed definition. From there, [API](/docs/concepts/api) explains how to expose your app over HTTP and call it programmatically. [Client](/docs/concepts/client) covers the typed HTTP client. [Tools](/docs/concepts/tools) explains how to let agents call your code. [Providers](/docs/concepts/providers) covers connecting to model APIs. [Events](/docs/concepts/events) shows how to observe runs in real time. [Persistence](/docs/concepts/persistence) explains durable conversations and stream resumption. [Plugins](/docs/concepts/plugins) covers cross-agent behavior like auth, logging, and rate limiting. [TypeScript](/docs/concepts/typescript) explains the end-to-end type inference story. [CLI](/docs/concepts/cli) covers portable type generation for separate client packages. [Structured Output](/docs/concepts/structured-output), [Human in the Loop](/docs/concepts/hil), [MCP](/docs/concepts/mcp), and [Errors](/docs/concepts/errors) cover the remaining features.
