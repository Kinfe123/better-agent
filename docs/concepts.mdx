# Concepts

These pages cover the building blocks of Better Agent — what each primitive is, what it does, and how the pieces connect.

Start with [Agent](/docs/concepts/agent) to understand the core unit, then [API](/docs/concepts/api) to see how an app exposes itself over HTTP. [Tools](/docs/concepts/tools) and [Structured Output](/docs/concepts/structured-output) cover the two main ways agents produce useful output. [Events](/docs/concepts/events) and [Persistence](/docs/concepts/persistence) handle observability and durability. [Plugins](/docs/concepts/plugins) and [Providers](/docs/concepts/providers) are the extension points. [TypeScript](/docs/concepts/typescript) and [CLI](/docs/concepts/cli) explain how type safety flows from server to client.
