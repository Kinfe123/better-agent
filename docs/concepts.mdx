# Concepts

Concept pages explain the mental model behind create-better-agent: the main primitives, how they fit together, and which page to open next when you want a deeper example or API surface.

## When to Use This Section
- Start with the page closest to the workflow you are trying to complete.
- Use setup and configuration pages before running commands in a new environment.
- Use reference pages when you already know the concept and need exact commands, imports, or options.

## Available Pages
- [Agent](/docs/concepts/agent) - The fundamental building block of Better Agent.
- [API](/docs/concepts/api) - Expose your Better Agent app over HTTP.
- [CLI](/docs/concepts/cli) - Generate portable client types from your Better Agent app.
- [Client](/docs/concepts/client) - Type-safe HTTP client for Better Agent servers.
- [Errors](/docs/concepts/errors) - Understand Better Agent error codes, shapes, and recovery.
- [Events](/docs/concepts/events) - Observe what happens during an agent run in real time.
- [Human in the Loop](/docs/concepts/hil) - Require human approval before a tool runs.
- [MCP](/docs/concepts/mcp) - Use MCP to connect agents to external tools and data.
- [Persistence](/docs/concepts/persistence) - Store and replay conversation history across runs.
- [Plugins](/docs/concepts/plugins) - Extend Better Agent with cross-agent behavior.
- [Providers](/docs/concepts/providers) - Connect Better Agent to model APIs.
- [Structured Output](/docs/concepts/structured-output) - Get typed, validated responses from your agents.
- [Tools](/docs/concepts/tools) - Let agents take structured actions.
- [TypeScript](/docs/concepts/typescript) - End-to-end type inference from server to client.
