# Agent

An agent is the core unit of behavior in Better Agent. It brings together a model, instructions, tools, and runtime behavior into one typed definition. At minimum, an agent needs a `name` and a `model`.

```ts
import { defineAgent } from "@better-agent/core";
import { openai } from "./openai";

export const helloAgent = defineAgent({
  name: "hello",
  model: openai.model("gpt-4o"),
});
```

You can add a `description` to help humans reading your agent definitions.

## Instructions and Context

Use `instruction` to define the agent's system behavior. It can be a static string or a function that receives validated context:

```ts
import { z } from "zod";

const supportAgent = defineAgent({
  name: "support",
  model: openai.model("gpt-4o"),
  contextSchema: z.object({
    userId: z.string(),
    plan: z.enum(["free", "pro"]),
  }),
  instruction: (context) =>
    `Help user ${context.userId}. They are on the ${context.plan} plan.`,
});
```

Use `contextSchema` to define typed, validated runtime data for a run — the current user, plan, workspace, or anything else your instruction needs. When you register the agent in `betterAgent()`, pass matching `context` when you run it.

## Tools

Tools let the agent act. Pass a single tool or an array:

```ts
const assistant = defineAgent({
  name: "assistant",
  model: openai.model("gpt-4o"),
  tools: [weatherTool, stockTool],
});
```

When a tool fails, the default behavior sends the error back to the model so it can recover. Use `toolErrorMode: "throw"` to stop the run instead. See [Tools](/docs/concepts/tools) for defining tools, client tools, approvals, and error recovery hooks.

## Steps

Each step produces one model response. If that response includes tool calls, the results feed into the next step. The loop continues until the model finishes naturally, a stop condition is met, or the step limit is reached.

Use `maxSteps` to cap how many steps a run can take:

```ts
const researcher = defineAgent({
  name: "researcher",
  model: openai.model("gpt-4o"),
  tools: [searchWeb, readPage],
  maxSteps: 5,
});
```

Use `stopWhen` when the run should stop based on your own workflow logic rather than the model's natural finish:

```ts
const researchAgent = defineAgent({
  name: "research",
  model: openai.model("gpt-4o"),
  contextSchema: z.object({ plan: z.enum(["free", "pro"]) }),
  tools: [searchWeb, readPage],
  maxSteps: 6,
  stopWhen: ({ stepIndex, context }) =>
    context.plan === "free" && stepIndex >= 1,
});
```
