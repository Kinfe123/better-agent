# CLI

The Better Agent CLI generates a `.d.ts` file from your app's agent definitions. This gives your client full type safety — typed agent names, context schemas, and tool contracts — without importing server code into the client bundle.

## Generate client types

```bash
npx @better-agent/cli generate type --config ./server.ts
```

Or with the global command:

```bash
better-agent generate type --config ./server.ts
```

The CLI discovers exported `betterAgent()` instances in the config file, extracts agent and tool type information, and writes a portable type declaration.

## Options

| Option | Default | Description |
| --- | --- | --- |
| `--config <path...>` | — | One or more config file paths. Required. |
| `--cwd <path>` | `process.cwd()` | Base directory for resolving relative paths. |
| `--out <path>` | `better-agent.types.d.ts` | Output path for the generated `.d.ts` file. |
| `--name <identifier>` | `BAClientApp` | Exported type alias name. |
| `--yes` | `false` | Skip prompts and overwrite the output file. |

## Example

```bash
npx @better-agent/cli generate type \
  --config ./server.ts \
  --out ./src/types/better-agent.d.ts \
  --name MyApp \
  --yes
```

This produces a file like:

```ts
// better-agent.types.d.ts
export type MyApp = {
  config: {
    agents: readonly [{
      name: "support";
      model: {
        caps: {
          structured_output: true;
          multi_turn: true;
        };
      };
      contextSchema: {
        userId: string;
        plan: "free" | "pro";
      };
    }];
  };
};
```

## Use the generated type

Import the type alias into your client:

```ts
import { createClient } from "@better-agent/client";
import type { MyApp } from "./src/types/better-agent";

const client = createClient<MyApp>({
  baseURL: "https://api.example.com",
  secret: process.env.BETTER_AGENT_SECRET!,
});
```

This gives you the same inference as importing `server.ts` directly, without any server code crossing the package boundary. See [TypeScript](/docs/concepts/typescript) for the full picture of how the type system connects server to client.
