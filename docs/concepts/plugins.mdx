# Plugins

Plugins add behavior that applies across your entire app: logging, auth, rate limiting, lifecycle hooks, and custom endpoints. Register them once at the app level and they apply to every agent.

```ts
import { betterAgent } from "@better-agent/core";
import { rateLimitPlugin, loggingPlugin } from "@better-agent/plugins";

export const app = betterAgent({
  agents: [myAgent],
  plugins: [
    rateLimitPlugin({ windowMs: 60_000, max: 20 }),
    loggingPlugin({ level: "info" }),
  ],
});
```

## Creating a Plugin

Use `definePlugin()` to create a custom plugin. Every plugin needs a unique `id`.

```ts
import { definePlugin } from "@better-agent/core";

export const myPlugin = definePlugin({
  id: "my-plugin",
});
```

A plugin can combine guards, lifecycle hooks, event middleware, event observation, tools, and custom endpoints.

## Guards

Guards run before a request is processed. Return `null` to allow the request, or return a `Response` to reject it.

```ts
const workspaceAuth = definePlugin({
  id: "workspace-auth",
  guards: [
    async ({ mode, agentName, request, input }) => {
      const token = request.headers.get("authorization");
      if (!token) {
        return new Response("Unauthorized", { status: 401 });
      }
      const workspace = await resolveWorkspace(token);
      if (!workspace) {
        return new Response("Invalid workspace", { status: 403 });
      }
      return null;
    },
  ],
});
```

The guard context includes `mode` (the request type), `agentName`, parsed `input`, and the raw `Request` object.

## Lifecycle Hooks

Use `onStep` to run code before each model step. You can mutate messages, set tool choice, filter active tools, or override the system instruction:

```ts
const contextInjector = definePlugin({
  id: "context-injector",
  onStep: async (ctx) => {
    if (ctx.stepIndex === 0) {
      ctx.updateMessages((messages) => [
        ...messages,
        { role: "system", content: `Current time: ${new Date().toISOString()}` },
      ]);
    }
  },
});
```

Other available hooks include `onStepFinish`, `onRunStart`, `onRunFinish`, and `onRunError`.

## Built-in Plugins

Better Agent ships several ready-to-use plugins in `@better-agent/plugins`. See [Auth](/docs/plugins/auth) for API key authentication, and the other plugin pages for rate limiting, logging, IP allowlisting, and sandboxing.
