# Get Started

Better Agent is a TypeScript framework for building typed, event-driven, framework-agnostic agent apps. This section covers everything you need to go from zero to a working app.

Start with [Introduction](/docs/get-started/introduction) to understand what the framework is and why it exists. Then follow [Installation](/docs/get-started/installation) to set up your packages, and [Usage](/docs/get-started/usage) to build your first agent, client, and UI in three files.
