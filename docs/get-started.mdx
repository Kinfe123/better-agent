# Get Started

Better Agent is a TypeScript framework for building typed, event-driven, framework-agnostic agent apps. This section covers everything you need to go from zero to a running agent in your project.

Start with [Introduction](/docs/get-started/introduction) to understand what Better Agent is and why it exists. Then follow [Installation](/docs/get-started/installation) to add the packages and configure your environment. [Usage](/docs/get-started/usage) shows you a working server, typed client, and UI in about thirty lines of code.

Once you're past the first run, the [Concepts](/docs/concepts) section covers the mental models — agents, tools, events, providers, persistence, and plugins — that you'll need to build production apps.
