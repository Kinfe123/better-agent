# Get Started

Better Agent is a TypeScript framework for building typed, event-driven agent apps. These pages take you from installing the packages to a working server, typed client, and UI — then into the deeper concepts you'll need as your app grows.

Start with [Introduction](/docs/get-started/introduction) to understand what Better Agent is and why it's built the way it is. Then follow [Installation](/docs/get-started/installation) to get the packages in place, and [Usage](/docs/get-started/usage) to build your first agent app end-to-end.
