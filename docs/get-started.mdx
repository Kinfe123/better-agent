# Get Started

Better Agent is a TypeScript framework for building typed, event-driven, framework-agnostic agent apps. These pages take you from zero to a working agent app.

Start with [Introduction](/docs/get-started/introduction) for the full picture of what Better Agent provides and why it's built the way it is. Then follow [Installation](/docs/get-started/installation) to get the packages into your project, and [Usage](/docs/get-started/usage) to build your first agent, client, and UI.
