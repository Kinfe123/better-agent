# Usage

Build a small Better Agent app across three files: `server.ts`, `client.ts`, and a UI component. Each step is self-contained—you can stop after any one of them and have something that runs.

## Define the server

Create a provider, define an agent, and export the Better Agent app.

```ts title="server.ts"
import { betterAgent, defineAgent } from "@better-agent/core";
import { createOpenAI } from "@better-agent/providers/openai";

const openai = createOpenAI({
  apiKey: process.env.OPENAI_API_KEY,
});

const helloAgent = defineAgent({
  name: "helloAgent",
  model: openai.text("gpt-5-mini"),
  instruction: "You are a friendly assistant. Keep answers short.",
});

const app = betterAgent({
  agents: [helloAgent],
  baseURL: "/api",
  secret: "dev-secret",
});

export default app;
```

`betterAgent()` returns both a programmatic API (`app.run()`, `app.stream()`) and an HTTP handler you can mount in any framework. See [API](/docs/concepts/api) for mounting instructions.

## Create a typed client

Import the server app's type to get full inference for agent names, inputs, outputs, and tool contracts. No runtime server code crosses into the client bundle.

```ts title="client.ts"
import { createClient } from "@better-agent/client";
import type app from "./server";

export const client = createClient<typeof app>({
  baseURL: "/api",
  secret: "dev-secret",
});
```

When the client and server live in separate packages, generate a portable `.d.ts` file with the CLI instead of importing the server type directly. See [CLI](/docs/concepts/cli) and [TypeScript](/docs/concepts/typescript) for details.

## Connect the UI

Pick the adapter that matches your framework. Each one exports `useAgent` (or `createAgentChat` for Svelte) and returns `messages`, `status`, `sendMessage`, and `stop`.

```tsx tab="React" title="src/App.tsx"
import { useState } from "react";
import { useAgent } from "@better-agent/client/react";
import { client } from "./client";

export default function Page() {
  const [input, setInput] = useState("");

  const { messages, status, sendMessage } = useAgent(client, {
    agent: "helloAgent",
  });

  return (
    <div>
      <p>Status: {status}</p>
      <ul>
        {messages.map((message) => (
          <li key={message.localId}>
            {message.role}:{" "}
            {message.parts
              .map((part) => (part.type === "text" ? part.text : ""))
              .join("")}
          </li>
        ))}
      </ul>
    </div>
  );
}
```

```vue tab="Vue" title="src/App.vue"
<script setup lang="ts">
import { ref } from "vue";
import { useAgent } from "@better-agent/client/vue";
import { client } from "./client";

const agent = useAgent(client, {
  agent: "helloAgent",
});

const input = ref("");
</script>

<template>
  <div>
    <p>Status: {{ agent.status.value }}</p>
    <ul>
      <li v-for="message in agent.messages.value" :key="message.localId">
        {{ message.role }}:
        {{
          message.parts
            .map((part) => (part.type === "text" ? part.text : ""))
            .join("")
        }}
      </li>
    </ul>
  </div>
</template>
```

```svelte tab="Svelte" title="src/App.svelte"
<script lang="ts">
  import { createAgentChat } from "@better-agent/client/svelte";
  import { client } from "./client";

  const chat = createAgentChat(client, {
    agent: "helloAgent",
  });

  let input = "";
</script>

<div>
  <p>Status: {$chat.status}</p>
  <ul>
    {#each $chat.messages as message (message.localId)}
      <li>
        {message.role}:
        {message.parts
          .map((part) => (part.type === "text" ? part.text : ""))
          .join("")}
      </li>
    {/each}
  </ul>
</div>
```

```tsx tab="Solid" title="src/App.tsx"
import { useAgent } from "@better-agent/client/solid";
import { For, createSignal } from "solid-js";
import { client } from "./client";

export default function Page() {
  const { messages, status, sendMessage } = useAgent(client, {
    agent: "helloAgent",
  });

  const [input, setInput] = createSignal("");

  return (
    <div>
      <p>Status: {status()}</p>
      <ul>
        <For each={messages()}>
          {(message) => (
            <li>
              {message.role}:{" "}
              {message.parts
                .map((part) => (part.type === "text" ? part.text : ""))
                .join("")}
            </li>
          )}
        </For>
      </ul>
    </div>
  );
}
```

From here, you can add tools, structured output, and persistence without changing this basic shape.
