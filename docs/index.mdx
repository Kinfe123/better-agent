# Introduction

Better Agent is a TypeScript framework for building agent apps that are typed end-to-end, from your server definition to your client calls. It gives you a single app primitive — `betterAgent()` — that handles the agent loop, HTTP routing, streaming, persistence, and plugin hooks, without forcing you to adopt a fixed runtime or application framework.

The framework fits into the stack you already have. Mount it on Next.js, SvelteKit, TanStack Start, Remix, Astro, Nuxt, Hono, Express, Fastify, Elysia, or any platform that speaks the Fetch standard. Define agents once with `defineAgent()`, attach tools with `defineTool()`, connect model providers for OpenAI, Anthropic, or xAI, and get a typed client that infers agent names, context schemas, and structured output without importing server code.

## Scaffolding a new app

The fastest way to start is `create-better-agent`, the official scaffolding CLI. It detects your framework, generates the Better Agent files, lets you choose providers and plugins, and writes the required environment variable stubs:

```bash
npm create better-agent
```

To add Better Agent to an app you already have, run it in patch mode:

```bash
npm create better-agent@latest -- --mode patch
```

Supported frameworks include `nextjs`, `sveltekit`, `tanstack-start`, `remix`, `astro`, `nuxt`, `solidstart`, `react-router`, and `generic`.
