# Installation

Better Agent is a TypeScript framework distributed as a set of focused packages. You install only what you need.

## Packages

Better Agent is split into six packages:

- `@better-agent/core` — agents, tools, events, and runtime primitives.
- `@better-agent/client` — typed HTTP client plus framework hooks for React, Vue, Svelte, Solid, and Preact.
- `@better-agent/providers` — adapters for OpenAI, Anthropic, and xAI.
- `@better-agent/plugins` — guards, lifecycle hooks, middleware, and runtime extensions.
- `@better-agent/adapters` — framework adapters for Express, Fastify, and other servers.
- `@better-agent/cli` — type generation for typed client packages and app definitions.

## Automatic setup

The `create-better-agent` CLI is the recommended way to get started. It scaffolds a new project or patches Better Agent into an existing one:

```bash
npm create better-agent
```

```bash
pnpm create better-agent
```

```bash
yarn create better-agent
```

```bash
bun create better-agent
```

The CLI detects your framework, generates the Better Agent files, lets you choose providers and plugins, and writes the required environment variable stubs. Supported frameworks: `nextjs`, `sveltekit`, `tanstack-start`, `remix`, `astro`, `nuxt`, `solidstart`, `react-router`, and `generic`.

## Manual setup

Use the manual path if you want full control over project structure.

**1. Create a TypeScript project** if you don't have one:

```bash
mkdir my-agent && cd my-agent
npm init -y
npm install typescript -D
npx tsc --init
```

**2. Install the packages you need:**

```bash
npm install @better-agent/core @better-agent/client @better-agent/providers
```

**3. Set your provider API key.** For OpenAI:

```bash
OPENAI_API_KEY=sk-...
```

**4. Verify the setup** by creating a minimal `server.ts` and running it:

```ts
import { betterAgent, defineAgent } from "@better-agent/core";
import { createOpenAI } from "@better-agent/providers/openai";

const openai = createOpenAI({ apiKey: process.env.OPENAI_API_KEY });

const hello = defineAgent({
  name: "hello",
  model: openai.model("gpt-4o"),
  instruction: "You are a helpful assistant.",
});

export const app = betterAgent({ agents: [hello], baseURL: "/api" });
```

If this compiles without errors, your setup is complete. Head to [Usage](/docs/get-started/usage) to wire up a typed client and UI.
