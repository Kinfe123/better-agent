# Auth

The auth plugin blocks requests unless they provide a valid API key. Use static keys for simple setups, or provide your own validation logic for database-backed or agent-specific rules.

## Basic Usage

By default the plugin reads the key from the `x-api-key` header:

```ts
import { authPlugin } from "@better-agent/plugins";

const plugin = authPlugin({
  apiKeys: ["dev-key"],
});
```

## Custom Header

Use `header` when your key lives in a different header:

```ts
const plugin = authPlugin({
  header: "authorization",
  apiKeys: ["Bearer dev-key"],
});
```

## Custom Validation

Use `getKey` and `validate` when you need your own auth logic — for example, when keys come from your database or when rules differ per agent:

```ts
const plugin = authPlugin({
  getKey: ({ request }) => request.headers.get("authorization"),
  validate: async ({ key, agentName }) => {
    const record = await db.apiKeys.findUnique({ where: { key } });
    return record !== null && record.allowedAgents.includes(agentName);
  },
});
```

If validation fails, the plugin returns `401 Unauthorized`.

## Registration

Add the plugin to your `betterAgent()` app:

```ts
import { betterAgent } from "@better-agent/core";
import { authPlugin } from "@better-agent/plugins";

export const app = betterAgent({
  agents: [myAgent],
  plugins: [
    authPlugin({
      apiKeys: [process.env.BETTER_AGENT_API_KEY!],
    }),
  ],
});
```

> **Note:** The built-in `secret` field on `betterAgent()` provides a simpler bearer token check for the HTTP layer. The auth plugin gives you more control — custom headers, per-agent rules, and database-backed validation.
