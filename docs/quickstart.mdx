# Quickstart

This page walks you through a minimal Better Agent app: a server module, a typed client, and a React UI component. By the end you'll have a working chat loop wired from model to browser.

## Define the server

Create a Better Agent app with one agent in `server.ts`:

```ts
import { betterAgent, defineAgent } from "@better-agent/core";
import { createOpenAI } from "@better-agent/providers/openai";

const openai = createOpenAI({
  apiKey: process.env.OPENAI_API_KEY,
});

const helloAgent = defineAgent({
  name: "helloAgent",
  model: openai.text("gpt-4o-mini"),
  instruction: "You are a friendly assistant. Keep answers short.",
});

const app = betterAgent({
  agents: [helloAgent],
  baseURL: "/api",
  secret: "dev-secret",
});

export default app;
```

## Create a typed client

Import the server app type so agent names, inputs, outputs, and tool contracts stay aligned:

```ts
import { createClient } from "@better-agent/client";
import type app from "./server";

export const client = createClient<typeof app>({
  baseURL: "/api",
  secret: "dev-secret",
});
```

When your client and server live in separate packages, use the generated type from the CLI instead. See [TypeScript](/docs/concepts/typescript) for details.

## Connect the UI

Use `useAgent` from the React adapter to wire the client into a component:

```tsx
import { useState } from "react";
import { useAgent } from "@better-agent/client/react";
import { client } from "./client";

export default function Page() {
  const [input, setInput] = useState("");

  const { messages, status, sendMessage } = useAgent(client, {
    agent: "helloAgent",
  });

  return (
    <div>
      <ul>
        {messages.map((message) => (
          <li key={message.localId}>
            {message.role}:{" "}
            {message.parts
              .map((part) => (part.type === "text" ? part.text : ""))
              .join("")}
          </li>
        ))}
      </ul>
      <input value={input} onChange={(e) => setInput(e.target.value)} />
      <button onClick={() => { sendMessage(input); setInput(""); }}>
        Send
      </button>
      <p>Status: {status}</p>
    </div>
  );
}
```

> **Note:** The Vue, Svelte, Solid, and Preact adapters follow the same pattern with framework-specific hooks. Mount the client and pick the adapter that matches your UI layer.

From here you can add [Tools](/docs/concepts/tools) to let the agent take actions, [Structured Output](/docs/concepts/structured-output) for typed JSON responses, and [Persistence](/docs/concepts/persistence) for durable conversations across page reloads.
